Pengenalan & Pengertian

💻

Hardware

Hardware adalah perangkat keras atau komponen fisik pada komputer yang dapat disentuh dan dilihat. Contohnya adalah CPU, RAM, motherboard, monitor, keyboard, SSD, NIC, router, dan switch.

🧩

Software

Software adalah program, instruksi, dan data yang mengatur cara kerja perangkat keras. Tanpa software, hardware hanya akan menjadi alat mati yang tidak dapat digunakan.

🔗

Peran dalam TKJ

Dalam dunia Teknik Komputer dan Jaringan, hardware menyediakan infrastruktur fisik serta jaringan, sedangkan software mengendalikan proses, keamanan, dan komunikasi data.

Perangkat Keras (Hardware)

Komponen utama sistem komputer dan jaringan

Input Device

  • Keyboard
  • Mouse
  • Scanner
  • Microphone

Process Device

  • CPU
  • RAM
  • Motherboard
  • GPU

Output Device

  • Monitor
  • Printer
  • Speaker
  • Projector

Storage Device

  • SSD/HDD
  • Flashdisk
  • DVD
  • Cloud Storage
🧠

CPU (Central Processing Unit)

CPU adalah otak komputer yang menjalankan instruksi program. Ia memproses data dan mengontrol kerja sistem secara keseluruhan.

⚡

RAM

RAM berfungsi sebagai memori kerja sementara. Semakin besar kapasitas RAM, semakin lancar komputer menjalankan banyak program secara bersamaan.

🛠️

Motherboard

Motherboard adalah papan utama yang menghubungkan semua komponen komputer agar dapat bekerja bersama dan saling berkomunikasi.

💾

SSD / HDD

Storage menyimpan sistem operasi, aplikasi, dan data. SSD lebih cepat dibanding HDD, tetapi umumnya lebih mahal.

🌐

NIC / LAN Card

NIC (Network Interface Card) memungkinkan komputer terhubung ke jaringan lokal atau internet. Komponen penting di bidang TKJ.

📶

Router & Switch

Router menghubungkan jaringan yang berbeda dan mengatur lalu lintas data antar jaringan. Switch menghubungkan perangkat dalam satu jaringan lokal.

Perangkat Lunak (Software)

Jenis software dan fungsi utamanya

🧰

Software Sistem

Software sistem adalah perangkat lunak yang mengelola sumber daya komputer dan memungkinkan software aplikasi berjalan. Contohnya: BIOS, driver, dan sistem operasi.

📱

Software Aplikasi

Software aplikasi digunakan untuk kebutuhan tertentu seperti mengetik dokumen, mengolah gambar, browsing, atau mengelola data. Contohnya: Microsoft Word, Chrome, Excel.

🛡️

Software Utilitas

Software utilitas bertugas menjaga kinerja, keamanan, dan pemeliharaan sistem komputer. Contohnya: antivirus, disk cleanup, backup software, dan defragmenter.

⚙️

Peran Software

Software memberi perintah kepada hardware agar dapat menjalankan tugas. Tanpa software, hardware tidak bisa melakukan pekerjaan yang diinginkan secara otomatis.

Sistem Operasi (Operating System)

OS sebagai pengelola sumber daya komputer dan jaringan

Windows

Terpopuler untuk PC dan perangkat kantor.

Kelebihan
  • Antarmuka user-friendly
  • Kompatibel dengan banyak software
  • Digunakan banyak orang
Kekurangan
  • Lisensi berbayar
  • Rentan terhadap malware
  • Resource lebih berat

Linux (Ubuntu/Debian)

Sistem operasi open-source yang stabil dan fleksibel.

Kelebihan
  • Gratis & open source
  • Stabil dan aman
  • Populer untuk server
Kekurangan
  • Awal penggunaan lebih sulit
  • Beberapa software windows belum kompatibel
  • Perlu konfigurasi manual

MikroTik RouterOS

Dirancang khusus untuk perangkat jaringan seperti router dan hotspot.

Kelebihan
  • Fitur jaringan lengkap
  • Stabil untuk routing dan firewall
  • Pengelolaan sederhana
Kekurangan
  • Lisensi terbatas pada perangkat tertentu
  • Kurang familiar bagi pemula
  • Pengaturan butuh pemahaman jaringan

Cisco IOS

Sistem operasi jaringan yang umum pada perangkat Cisco.

Kelebihan
  • Standar industri jaringan
  • Fitur routing dan switching kuat
  • Digunakan di perusahaan besar
Kekurangan
  • Harga lisensi tinggi
  • Operasi lebih kompleks
  • Butuh sertifikasi dan latihan

Debian

Linux yang stabil dan sering dipakai untuk server dan sistem jaringan.

Kelebihan
  • Stabil untuk server
  • Keamanan tinggi
  • Gratis dan reliable
Kekurangan
  • Konfigurasi lebih teknis
  • Kurang familiar untuk pengguna umum
  • Update bisa memakan waktu

Ubuntu

Versi Linux yang lebih ramah untuk pengguna desktop dan server.

Kelebihan
  • UI mudah dipelajari
  • Komunitas besar
  • Cocok untuk pembelajaran Linux
Kekurangan
  • Belum semua software berjalan sempurna
  • Butuh adaptasi dari pengguna Windows
  • Beberapa driver mungkin tidak langsung tersedia
📊

Fungsi OS

Sistem Operasi (OS) mengatur komunikasi antara hardware, software, dan pengguna. OS bertugas:

  • Mengelola CPU, RAM, dan storage
  • Mengatur proses input dan output
  • Menjalankan aplikasi
  • Menjaga keamanan dan akses perangkat
  • Memudahkan user berinteraksi dengan komputer
Komponen Fungsi
Kernel Mengelola sumber daya sistem
Shell Antarmuka untuk user berinteraksi
Driver Menghubungkan hardware dengan OS
File System Menyusun dan mengelola data
